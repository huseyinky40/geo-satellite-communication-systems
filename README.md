# geo-satellite-communication-systems
Python simulation suite for a GEO satellite communication link (Türksat 4A reference). Covers link budget, BER for BPSK/QPSK/8-PSK/16-QAM, Shannon capacity, free-space path loss, and ITU-R P.838 rain attenuation. Monte Carlo validation included. LEEN354 – Istanbul Arel University.
